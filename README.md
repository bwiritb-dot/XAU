# ⚱️ XAUG — Google Chrome Браузерное Приложение / Расширение

Полноценный торговый терминал стратегии по золоту (**XAUUSDT 15m**) в формате браузерного расширения для **Google Chrome** (Manifest V3).

---

## 🚀 Как установить в Google Chrome за 1 минуту:

1. Откройте браузер **Google Chrome**.
2. В адресной строке введите:
   ```text
   chrome://extensions/
   ```
   и нажмите **Enter**.
3. В правом верхнем углу включите переключатель:
   **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите кнопку:
   **«Загрузить распакованное расширение»** (*Load unpacked*).
5. В открывшемся окне выберите папку:
   ```text
   c:\Users\CDTX25\Desktop\AG\XAUG
   ```
6. Нажмите **«Выбор папки»**.

🎉 **Готово!** Расширение **XAUG** установлено и появится на панели расширений Chrome.

---

## 📱 Как пользоваться:

- **Клик по значку в панели Chrome**: открывает быстрый виджет с текущей котировкой, готовностью сигналов (% W и % R) и статусом бокса.
- **Кнопка «🚀 ОТКРЫТЬ ПОЛНЫЙ ТЕРМИНАЛ»**: открывает интерактивный терминал с графиком TradingView, мировыми часами, всеми индикаторами и звуковыми алертами в отдельной вкладке на весь экран.
- **Прямой запуск**: вы также можете в любой момент открыть `index.html` прямо в браузере или запустить через локальный сервер.

## ⚙️ Включенные модули и правила:
- **Метки сигналов со стрелками**:
  - `W 88%` — Зеленый треугольник снизу свечи (Покупка с расчетом вероятности)
  - `R 84%` — Красный треугольник над свечой (Продажа с расчетом вероятности)
- **Ступенчатая фиксация прибыли**:
  - **TP1 (+0.50%)**: фиксация 50% объема ➔ Стоп в Безубыток (Б/У)
  - **TP2 (+0.75%)**: фиксация 25% объема ➔ Стоп в защиту +0.50%
  - **TP3 (+1.00%)**: закрытие оставшихся 25% объема
- **Правило 4 часов**: полностью отключено.
- **Фильтр «Зона смерти»**: блокировка ложных сигналов в уикенд (Пт 12:00 — Пн 12:00).
