# XAUG lab — перебор параметров WSB A и Разворота B

План: [docs/superpowers/plans/2026-10-21-xaug-lab.md](../docs/superpowers/plans/2026-10-21-xaug-lab.md) · состояние: [STATUS.md](STATUS.md).

## Запуск на Windows одной командой

Нужно: Node 20+ и Python 3.11+ в PATH (`node -v`, `python --version`).

```
lab\run.cmd
```

Что происходит:

| Шаг | Файл | Время на i5-11400F (≈) |
|---|---|---|
| Свечи PAXGUSDT (с 2020-08) и XAUUSDT (с 2025-12) с data.binance.vision | `fetch.mjs` → `data/` | ≈ 30 с |
| Сверка движка с `XAUG-v2/src/core.js`, скорость, перенос PAXG → XAUUSDT | `check.mjs` → `out/check.json` | ≈ 5 с |
| Optuna → сетка → проверка по 9 окнам | `optimize.py` → `out/results.json` | ≈ 20–30 мин на 12 потоках |
| Отчёт, открывается в браузере | `report.py` → `report.html` | ≈ 1 с |

Ключи `optimize.py` (передаются через `run.cmd`): `--trials 2000` прогонов Optuna на окно,
`--grid 5` значений на переменную сетки, `--top 5` переменных в сетке, `--workers N` процессов
(по умолчанию — все потоки), `--quick` — дымовой прогон за ≈ 20 с.

## Что внутри

- `engine.mjs` — обе стратегии с параметрами на входе; с параметрами по умолчанию даёт те же
  метки входов и выходов, что `core.js` (проверка: `node --test lab/` и `node lab/check.mjs`).
- PnL сделки = Σ доля × ход цены − 0,04 % комиссии один раз; победа — PnL > 0.
- Окна: подбор 24 мес → проверка 6 мес → сдвиг 6 мес; на подборе берутся наборы со средней
  сделкой > 0 и ≥ 50 сделок; лучший — по win rate (до 1 п.п.) → RR (до 0,05) → числу сделок.
- XAUUSDT: каждый набор проверяется на тех же 6-месячных отрезках, что и на PAXG
  (с декабря 2025); условие владельца — лучший набор WSB должен быть там в плюсе.
- `data/` и большие файлы в git не кладутся; `out/results.json` и `report.html` — кладутся.
